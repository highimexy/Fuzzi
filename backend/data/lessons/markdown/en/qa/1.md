# Binary & Hex Systems

To understand how computers "think," we must look past the interface and into the raw logic of bits and bytes. Binary and Hexadecimal are the fundamental languages of all hardware and software.

## Binary: The Language of Circuits

Binary is a base-2 number system. It only uses two digits: `0` and `1`.

- **0**: Represents "off" (low voltage).
- **1**: Represents "on" (high voltage).

Every character, image, and instruction you see on your screen is eventually reduced to a sequence of these two digits.

### Why do we care as QA?

When testing, you'll encounter binary often in:

- **Network Packets:** Raw data transmission.
- **File Headers:** Identifying file types (e.g., `89 50 4E 47` for PNG).
- **Bitmasking:** Using bits to represent flags (e.g., read/write/execute permissions).

## Hexadecimal: The Developer's Shortcut

Writing out long strings of binary (`110101011011`) is tedious and prone to error. Hexadecimal (base-16) solves this.

Hex uses digits `0-9` and letters `A-F`:

- `A` = 10, `B` = 11, `C` = 12, `D` = 13, `E` = 14, `F` = 15.

> **Pro Tip:** One Hex digit represents exactly 4 bits (a nibble). Two Hex digits represent 8 bits (a full byte). This makes it the standard way to inspect memory or disk data.
