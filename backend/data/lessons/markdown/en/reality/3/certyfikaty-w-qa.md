# Certyfikaty w QA — ISTQB i Co Naprawdę Liczy Się w Rekrutacji

Certyfikat ISTQB to pierwsza rzecz którą senior QA poleci junior QA. Ale czy warto? Odpowiedź jest bardziej złożona niż "tak" lub "nie".

## ISTQB — Co To Jest

ISTQB (International Software Testing Qualifications Board) to międzynarodowy standard certyfikacji QA.

**Struktura:**
```
Foundation Level (FL) ← zacznij tu
  │
  ├── Advanced Level Test Manager (ALTM)
  ├── Advanced Level Test Analyst (ALTA)
  └── Advanced Level Technical Test Analyst (ALTTA)
        │
        └── Expert Level (nie ma tego w Polsce prawie)
```

**ISTQB Foundation Level — co obejmuje:**
- Podstawy testowania (co to jest testowanie, psychologia)
- Cykl życia oprogramowania
- Techniki testowania (black-box, white-box)
- Zarządzanie testowaniem
- Narzędzia

**Egzamin:**
- 40 pytań multiple choice, 60 minut
- Passing score: 65% (26/40)
- Koszt: ~300-400 PLN za egzamin (plus opcjonalnie kurs: 500-2000 PLN)
- Można zdać bez kursu (samodzielna nauka z sylabus + mock exams)

## Wartość ISTQB w Rekrutacji

**Kiedy certyfikat pomaga:**
```
1. Junior szukający pierwszej pracy
   - Sygnalizuje zaangażowanie w naukę
   - "Poważne podejście do zawodu" dla HR screeningu
   - Daje wspólny język podczas rozmowy technicznej

2. Korporacje i duże firmy
   - Często wymienione w job requirements
   - Procurement/enterprise clients wymagają certyfikatów od vendorów
   - Formalne procesy HR gdzie certyfikat = checkbox

3. Konsulting i outsourcing
   - Firmy consultingowe używają certyfikatów do sprzedania senioritu klientom
```

**Kiedy certyfikat NIE pomaga:**
```
1. Startupy i scale-upy
   - "Nie obchodzi nas ISTQB, pokaż jak testujesz" 
   - Praktyczne umiejętności > papier

2. Firmy z silną kulturą inżynierską
   - GitHub portfolio > certyfikaty
   - Portfolio z automatyzacją > ISTQB Foundation

3. Kiedy masz już doświadczenie
   - 3 lata doświadczenia > Foundation Level (który jest dla juniorów)
```

## Alternatywne Certyfikaty

**Selenium / WebDriver:**
Nie ma oficjalnego certyfikatu — praktyczne demo na rozmowie jest ważniejsze.

**Certified Agile Tester (CAT):**
Mniej znany, bardziej praktyczny niż ISTQB Advanced.

**AWS / Azure / GCP:**
Dla QA pracujących z cloud infrastructure i DevOps. Cloud practitioner lub associate level może wyróżnić profil.

**Kubernetes / Docker:**
Certified Kubernetes Administrator (CKA) — wartościowe dla QA w środowiskach kontenerowych.

**Security certifications:**
- CompTIA Security+: dobry fundament bezpieczeństwa
- OSCP: dla QA w security testing (pen testing)

## Jak Przygotować Się do ISTQB

**Self-study path (bez kursu):**
```
1. Pobierz official syllabus (darmowy na istqb.org)
2. Przeczytaj syllabus 1-2 razy
3. Zrób 3-4 zestawy mock exams (darmowe online: "ISTQB mock exam")
4. Sprawdź wyjaśnienia złych odpowiedzi — to jest nauka
5. Powtórz słabe obszary
6. Zrób kolejne mock exams aż będziesz stabilnie 80%+ przed egzaminem
```

**Typowe pułapki:**
```
- Pytania są precyzyjne językowo — "NAJLEPSZY" vs "DOBRY" zmienia odpowiedź
- Terminologia ISTQB jest specyficzna (np. "test basis" ma konkretne znaczenie)
- Ucz się definicji, nie tylko intuicji
```

## Co Naprawdę Liczy Się w Rekrutacji (według Senior QA)

```
Co senior QA szuka u kandydatów na technical interview:

1. Jak myślisz o testowaniu? (zadaj mi pytanie o feature, a zapytam jak to przetestujesz)
2. Czy masz przykłady trudnych bugów które znalazłeś?
3. Czy rozumiesz co testowanie NIE może zagwarantować?
4. Jak reagujesz gdy developer odrzuca Twój bug?
5. Portfolio: napisałeś testy automatyczne? Pokaż kod.

Certyfikat nie jest na tej liście — ale nie zaszkodzi.
```

**Hierarchia wartości:**
```
1. Praktyczne umiejętności testowania (najważniejsze)
2. Portfolio (kodu, testów, wkład w projekty)
3. Komunikacja i soft skills
4. Znajomość narzędzi
5. Certyfikaty (nice to have, nie deal-breaker)
```

## Rekomendacja

```
Junior (0-1 rok):
→ Zrób ISTQB Foundation jeśli celujesz w korporację lub masz czas.
→ Priorytet: portfolio i praktyczne umiejętności.

Mid (2-4 lata):
→ ISTQB Advanced jeśli pracodawca za to płaci lub wymaga.
→ Rozważ certyfikat cloud/automation zamiast ISTQB.

Senior (5+ lat):
→ Certyfikaty mają mniejsze znaczenie niż Twoje doświadczenie.
→ Specjalizuj się (security, performance, cloud) — to ma wartość rynkową.
```
