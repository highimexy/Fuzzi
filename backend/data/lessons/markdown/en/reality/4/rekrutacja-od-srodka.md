# Rekrutacja w IT — Jak To Naprawdę Wygląda

Rozmowy kwalifikacyjne w branży IT mają swój specyficzny format. Wiedząc jak ten proces wygląda od środka rekrutera, możesz się lepiej przygotować.

## Typowy Proces Rekrutacji QA

```
1. Screening CV (5–15 minut)
2. Rozmowa telefoniczna z HR (30 min)
3. Zadanie domowe lub rozmowa techniczna (1–3h)
4. Rozmowa z teamem/liderem technicznym (60 min)
5. Oferta / odrzucenie
```

Czas całego procesu: 2–6 tygodni, czasem dłużej.

## Jak Rekruterzy Czytają CV

Pierwsze 10 sekund: tytuł, firma, tech stack.
Następne 30 sekund: ciągłość zatrudnienia, technologie pasujące do oferty.

**CV QA checklist:**
- Jasny tytuł (QA Engineer, Software Tester, SDET)
- Lista technologii: Selenium/Playwright, Postman, Jira, SQL, język programowania
- Konkretne osiągnięcia: "Zautomatyzowałem 200 test cases, skracając czas regresji z 8h do 40min"
- Bez ogólników: "Odpowiedzialny za testowanie aplikacji" = nic nie mówi

## Zadania Domowe — Czego Szukają

Typowe zadania dla QA:
1. Napisz test cases dla podanej funkcji
2. Sprawdź tę stronę i napisz bug report
3. Napisz skrypt automatyzujący podane czynności

Oceniają:
- Kompletność (happy path + edge cases)
- Jakość raportów bugów (reprodukcja, severity, priorytet)
- Jakość kodu (czytelność, struktura, czy w ogóle działa)

## Popularne Pytania Techniczne QA

- "Czym różni się testowanie black box od white box?"
- "Jak byś przetestował formularz logowania?"
- "Co zrobisz gdy developer odmawia naprawienia buga?"
- "Czym jest piramida testów?"

**Pro tip:** Myśl na głos. Rekruterzy chcą widzieć Twój proces myślenia, nie tylko odpowiedź.

## Negocjacja Oferty

Zawsze negocjuj. Pierwsza oferta to rzadko najlepsza.

- ~70% kandydatów nie negocjuje
- ~85% firm ma margines 10–20% na negocjacje
- Prosty counter: "Rozważałem X PLN, czy jest możliwość zbliżenia się do tej liczby?"
