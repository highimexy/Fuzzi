# Finanse w IT — Jak Nie Przepalić Dobrego Wynagrodzenia

IT płaci dobrze. Ale wysokie wynagrodzenie bez planu finansowego = dużo zarobione, mało zostaje. QA który rozumie podstawy finansów osobistych buduje bezpieczeństwo, a nie tylko konsumuje.

## Dlaczego To Jest Temat dla QA

Wielu programistów i QA zarabia powyżej mediany — i żyje od pierwszego do pierwszego. Powód: brak planu, inflacja stylu życia, brak oszczędności.

Z drugiej strony: ktoś kto zarabia 10k PLN netto i oszczędza 20% = 2k/miesiąc = 24k/rok = po 10 latach 240k + odsetki/inwestycje. Wolność finansowa jest dostępna dla IT przy podstawowej dyscyplinie.

## Podstawy — Zanim Zaczniesz Inwestować

### Fundusz Awaryjny

Zanim cokolwiek inwestujesz: zbuduj poduszkę bezpieczeństwa.

```
Fundusz awaryjny = 3-6 miesięcznych wydatków
Przykład: wydajesz 5000 PLN/miesiąc → fundusz = 15,000-30,000 PLN
Gdzie: konto oszczędnościowe z natychmiastowym dostępem (nie inwestycje)
Po co: utrata pracy, choroba, awaria samochodu — bez konieczności zadłużania się
```

### Prosta Budżetowa Reguła 50/30/20

```
50% → Potrzeby (mieszkanie, jedzenie, transport, ubezpieczenia)
30% → Chcenia (restauracje, rozrywka, subskrypcje, zakupy)
20% → Oszczędności / inwestycje

Przy 8000 PLN netto:
- 4000 → potrzeby
- 2400 → chcenia
- 1600 → oszczędności
```

To nie jest sztywna reguła — dostosuj do swojej sytuacji. Ale 0% oszczędności to błąd.

## Inflacja Stylu Życia — Pułapka IT

Dostałeś podwyżkę z 6k na 9k? Teraz masz "więcej" na wydatki?

Lifestyle creep: każdy wzrost wynagrodzenia automatycznie generuje nowe wydatki (droższe mieszkanie, droższy samochód, droższa restauracja).

```
Antidotum: "Podwyżkę oszczędzam" — zanim zaczniesz wydawać więcej,
najpierw zwiększ oszczędności o tę samą kwotę.

Przykład: podwyżka +1500 PLN netto
→ +1000 PLN do inwestycji/oszczędności
→ +500 PLN do "chcenia"
```

## Podstawy Inwestowania w Polsce

### PPK (Pracownicze Plany Kapitałowe)

Jeśli pracodawca oferuje PPK — zapisz się. Pracodawca dopłaca do Twoich składek (zazwyczaj 1.5% wynagrodzenia brutto). To jest darmowy bonus.

### IKE / IKZE (Indywidualne Konto Emerytalne)

Konta ze zwolnieniami podatkowymi. IKZE daje odliczenie od podatku w bieżącym roku. Limit wpłat w 2024: ~9,400 PLN/rok dla IKZE.

Dla kogo: odkładasz na emeryturę, chcesz ulgę podatkową.

### ETF i Fundusze Indeksowe

Nie musisz wybierać akcji. ETF (np. Vanguard FTSE All-World lub iShares MSCI World) kupuje automatycznie cały rynek globalny.

```
Strategia beginners:
- Brokerzy: mBank, Santander, XTB (brak opłat za ETF)
- ETF: jeden globalny ETF (np. IWDA lub VWCE)
- Strategia: regularnie kupuj co miesiąc, niezależnie od rynku (Dollar Cost Averaging)
- Horyzont: 10-20 lat
```

### Czego UNIKAĆ

- Produkty strukturyzowane z pewnymi zyskami — zazwyczaj zysk tylko dla banku
- Crypto jako "plan emerytalny" — spekulacja, nie inwestycja
- Forex trading — 80-90% traci pieniądze
- MLM "inwestycje" — piramidy finansowe
- "Gorące" akcje od znajomych

## Kontrakt B2B — Optymalizacja Podatkowa dla QA

Przy wynagrodzeniu > 10k PLN netto, warto rozważyć B2B:

```
Umowa o pracę: 12k brutto → ~8,700 netto (po ZUS, podatku)
B2B JDG ryczałt 8.5%: 12k faktury → ~9,800 netto (przy prawidłowej konfiguracji)

Różnica: ~1,100 PLN miesięcznie = ~13,200 PLN rocznie
```

B2B wymaga:
- JDG lub spółka
- Samodzielne odprowadzanie ZUS (min. ~1700 PLN/miesiąc)
- Rozliczenie VAT (jeśli nie korzystasz ze zwolnienia)
- Wyższe wynagrodzenie brutto żeby się opłaciło (zazwyczaj > 8-9k PLN brutto)

Skonsultuj z księgowym przed decyzją.

## Plan Finansowy dla QA — Praktycznie

```
Rok 1: Podstawy
□ Fundusz awaryjny: 3 miesiące wydatków
□ Zapisz się do PPK
□ Zacznij IKZE (nawet 200 PLN/miesiąc)

Rok 2-3: Inwestowanie
□ IKE + IKZE do maksimum
□ Konto maklerskie + ETF globalny
□ Budżet miesięczny jest jasny i trzymasz się go

Rok 5+: Optymalizacja
□ Rozważ B2B jeśli zarobki rosną
□ Nieruchomość? (tylko jeśli masz wkład własny i fundusz awaryjny)
□ Kolejne konta inwestycyjne
```

## Rozmawiaj o Wynagrodzeniu

W IT wciąż jest kultura nie rozmawiania o zarobkach. To szkodzi pracownikom, nie pracodawcom.

Jak dowiedzieć się ile powinieneś zarabiać:
- **No Fluff Jobs** — mediany dla konkretnych ról i miast
- **Bulldogjob** — widełki w ofertach
- **Pracuj.pl Barometr Wynagrodzeń** — dane roczne
- **Zapytaj kolegów z branży** — normalna rozmowa, nie secret

Jeśli zarabiasz poniżej mediany dla Twojego doświadczenia i lokalizacji — masz argument do negocjacji lub szukania nowej pracy.
